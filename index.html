03 /The next chapter

PRE-V1 · IN DEVELOPMENT

One program.
Your entire node.
Meet Z23.

An independent Zclassic full node, written in C23. Download the chain from peers and verify every block yourself — including the proofs behind shielded payments.

Explore Z23 on GitHub
build-your-own.sh
$ git clone https://github.com/z23c/z23.git
$ cd z23 && make setup && make -j z23
$ build/bin/z23
Native C23No Rust toolchainBuild from source

Status: pre-v1, under active development and measured against eight public acceptance criteria, including consensus parity with zclassicd. github.com/z23c/z23

Verify locally.

Shielded proof verification is native C23, with the verifying keys compiled in. No Rust, and no proving parameters needed to sync.

Tor, built in.

Tor is bundled, on by default, and the node publishes its own .onion. It trusts no DNS seeder and no certificate authority.

Your own explorer.

The node serves an explorer and a JSON API itself, with no reverse proxy or hosted service in front.

Wallet + RPC.

Transparent and shielded wallet state, and an RPC interface for your own tools.

Built to recover.

A fresh node starts honestly empty and reports why when it can't make progress. It is designed to survive kill -9.

Answers to you.

One executable you build and run on your own machine. Its optional software commons keeps code only when you accept that exact version.
