New · open source

Z23: the Zclassic full node in one C23 program.

Z23 is an independent, from-source ZClassic node written in C23. It downloads the chain from peers and checks every block itself: proof-of-work, scripts and the zero-knowledge proofs behind shielded payments.

  • Verifies everything locally. Shielded proof verification is native C23, with the verifying keys compiled in. No Rust, and no proving parameters needed to sync.
  • Tor built in. Tor is bundled, on by default, and the node publishes its own .onion. It trusts no DNS seeder and no certificate authority.
  • Its own block explorer. The node serves an explorer and a JSON API itself, with no reverse proxy or hosted service in front.
  • Wallet and RPC. Transparent and shielded wallet state, and an RPC interface for your own tools.
  • Built to recover. A fresh node starts honestly empty and reports why when it can't make progress. It is designed to survive kill -9.
  • Answers to you. One executable you build and run on your own machine. Its optional software commons keeps code only when you accept that exact version.
git clone --recurse-submodules https://github.com/z23c/z23.git
cd z23 && make doctor && make setup
make -j"$(getconf _NPROCESSORS_ONLN)" z23
build/bin/z23

Status: pre-v1, under active development and measured against eight public acceptance criteria, including consensus parity with zclassicd. There is no prebuilt Z23 binary yet: build it from source as above. The downloads above are the zclassicd node and wallet.
